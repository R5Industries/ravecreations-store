# Deploying the RAVE Creations store

Separate Cloudflare Worker (`ravecreations-store`) at **https://shop.ravecreations.art**,
linked from the marketing site (`PUBLIC_STORE_URL`, default `https://shop.ravecreations.art`).
Based on [minshop](https://github.com/ddyy/minshop); payments are **Stripe Checkout only**.

Nothing below has been run. Every step that touches Cloudflare or Stripe is yours to approve.

## 1. Provision Cloudflare resources

Names are already set in `wrangler.jsonc`. Requires Node 22+ and `bunx wrangler login`.

```bash
bunx wrangler d1 create ravecreations-store-db        # copy the printed database_id
bunx wrangler r2 bucket create ravecreations-store-images
bunx wrangler r2 bucket create ravecreations-store-files   # PRIVATE: never enable r2.dev or a custom domain
```

Add the `database_id` to the `DB` entry in `wrangler.jsonc` (or let `wrangler deploy` create it).
Then apply the schema:

```bash
bun run db:migrate:remote
```

Optional sample catalog + placeholder photos (skip if you will add real products in Admin):

```bash
bunx wrangler d1 execute DB --remote --file=./rave/seed.sql
bash rave/seed-images.sh --remote
```

## 2. Worker secrets (you paste these)

Only two are required, generated by you and **different from each other**:

```bash
openssl rand -base64 32 | bunx wrangler secret put AUTH_SECRET
openssl rand -base64 32 | bunx wrangler secret put SECRETS_KEK
```

Do not commit them. `.dev.vars` (local only) is gitignored.

## 3. Deploy

```bash
bun run deploy
```

## 4. Custom domain `shop.ravecreations.art`

Zone `ravecreations.art` must be on this Cloudflare account. Either:

- Dashboard: Workers & Pages → `ravecreations-store` → Settings → Domains & Routes → Add → Custom domain → `shop.ravecreations.art`; or
- add to `wrangler.jsonc` and redeploy:
  `"routes": [{ "pattern": "shop.ravecreations.art", "custom_domain": true }]`

Afterwards (optional performance): set `"workers_dev": false`, `vars.CANONICAL_ORIGIN = "https://shop.ravecreations.art"`
and `cache.enabled = true` (see README → Caching).

## 5. First-run setup and Stripe

1. Open `https://shop.ravecreations.art/admin/setup` **immediately** (it is open until a password exists)
   and set the admin password. Consider fronting `/admin` and `/api/admin` with Cloudflare Access.
2. Admin → Settings → Payments → **Card (Stripe)**: paste in the admin UI (stored encrypted):
   - Stripe **secret key** `sk_live_…` (use `sk_test_…` first)
   - Webhook **signing secret** `whsec_…`
3. Stripe Dashboard → Developers → Webhooks → add endpoint
   `https://shop.ravecreations.art/api/webhook/stripe` with events:
   `checkout.session.completed`, `checkout.session.async_payment_succeeded`,
   `checkout.session.async_payment_failed`, `checkout.session.expired`, `charge.refunded`.
   Copy its `whsec_…` into step 2.
4. Set the default payment rail to Stripe and **turn off the Demo rail** before going live.
5. Admin → Shipping: confirm the US zone (Standard $5, free from $50, Phoenix pickup) was saved.
   Admin → Settings → Store name `RAVE Creations`, time zone `America/Phoenix`.
6. Optional: Stripe Tax (activate in Stripe first), Resend key for order emails, Turnstile.
